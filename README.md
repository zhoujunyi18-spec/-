# JRPGリメイク作品におけるゲーム要素別の評価

Steam日本語レビューを対象とする修士論文研究プロジェクトです。現在は文献調査・データ監査・先導調査の準備段階です。

## 分析の焦点

ゲーム要素ごとの現在評価と、明示的な旧版比較における相対評価を分けて記録します。推薦／非推薦は本文中の評価方向の代用にしません。

## 現在の状態

- Steam公式APIによる4作品の日本語レビュー収集を実行中。
- 日英の関連論文を一次資料に照らして確認中。
- 独立した人手検証は未実施。LLMの再判定を人手検証とは呼びません。
- 本稿は実施段階に応じて更新します。未確認の数値・文献・結果は確定的に記述しません。

## データ方針

投稿者の識別情報、レビュー全文、出版社の論文PDFはこの公開リポジトリに登録しません。集計値、取得手順、コードブック、分析コードと取得記録を公開する予定です。
