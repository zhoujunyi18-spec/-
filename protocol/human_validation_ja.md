# 独立人手検証の実施手順

実施は未了。ユーザーの指定により、AI先導分析・初稿作成の後に行う。

ローカルファイル `data/private/validation/blind_annotation.csv` に正式4作品各50件、計200件を用意した。先導120件およびSO2R診断30件と重複しない。推薦フラグとAIラベルは表示していない。投稿者情報も不要なため含めない。

1. 最終コードブックを凍結し、検証標本以外で練習する。
2. 第一の人が全文を読み、各要素・下位対象・現在極性・比較の有無・参照版・比較関係・方向・原文根拠を記録する。空欄は未作業と区別し、NONEと明記する。
3. 第二の人が少なくとも無作為抽出した50件を独立にコード化する。相手のラベルを見てから付けたラベルは独立とは呼ばない。比較の陽性が少ない場合は検証範囲を増やす。
4. 個々の判定の一致と、両者が根拠とした範囲を照合する。合議前のラベルと合議後のラベルを両方保存する。
5. 人手基準に対するAIのprecision、recall、F1を報告する。比較検出と相対方向を分け、要素＋対象＋参照版＋方向の複合誤りも報告する。
6. 200件で陽性が十分得られるとは限らない。追加の比較候補を濃縮抽出して誤り診断に使う場合、無作為検証群と混ぜて母集団割合を計算しない。

ASCII英語・空白・引用だけ・皮肉・複数旧版・他作品比較・同一リメイクのパッチ比較を必ず点検する。特に「親切すぎる」「容易になった」「良い部分を残す」の方向は、根拠そのものから判定する。

移行条件はコードブックを参照。達成しなければルール変更後に新しい独立標本を確保する。今回の人手検証標本を調整に使った場合、その後は独立評価用として再利用しない。
